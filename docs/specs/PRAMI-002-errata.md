# PRAMI-002 스펙 정오표 (errata)

PRAMI-002 원본 스펙(`PRAMI-002-langgraph-chatbot.md` r5)은 Windows 시절 경로에만 있고 현재 저장소와 호스트에는 없다. Main 결정(`msg_0afe5fe36223`, 2026-10-06)에 따라 원본을 옮기지 않는다. 정정 사항은 이 문서에만 기록하며, 이 문서가 원본보다 우선한다.

## E-1. R-16 문구 정정 (Issue #17 I-2)

- 근거: Issue #17 본문 I-2와 PR #16 QA INFO.
- 실제 동작: 출력 가드는 같은 문장에 원가 단어와 금액(또는 비율)이 있는 경우, 그리고 원가 키 JSON만 판정한다(`guard.ts` `mentionsCostAmount`). 키 모양 문자열이나 시스템 프롬프트 문구는 판정 대상이 아니다. 벤더가 거부하면 `discard()`만 호출한다.
- **정정 전 (이슈 인용)**: 보호 대상(원가·키)은 출력 가드가 독립적으로 막는다.
- **정정 후**: **원가는 출력 가드가, 키는 컨텍스트 부재(AC-228)로 막는다.** 거부 전에 나간 문장에 시스템 프롬프트나 키 모양 문자열이 있으면, token으로 출력된 뒤 discard된다. 이는 수용한 잔여 위험이다.
