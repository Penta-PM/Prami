## 1. 사실
- 업로드 칸은 3개, 모두 공용 `ImportFileRow`:
  - 가격정책 관리 `ImportPanel`: ① 판매단가 파일(`kind="sales"`) → 항목 1, ② 품목상태 파일(`kind="items"`, 1~5개 한 칸) → 항목 2
  - 원가 관리 `CostImportPanel`: 원가 파일(`kind="costs"`) → 항목 3 (기존 note "구매단가등록 12컬럼…" 있음)
- 항목 4(품목-원가 매칭)는 업로드 기능 없음. 매핑 화면 `/admin/costs/links`.
- 아이콘 패키지 없음 — 자체 SVG 세트(`features/shell/icons.tsx`). Tooltip 프리미티브 없음, 비모달 `Popover`(열 필터)는 있음.
- 기존 임포트 파이프라인은 파싱 행을 `stg_*` 에 `raw` 로 적재 → 기밀 매칭 파일에는 재사용 불가(항목 4 업로드를 만든다면 별도 설계).

## 6. Main 답 반영 (2026-10-22, msg_961ad62089ee — 사용자 확인)
### 6.1 Q-E1 — 공통 설명도 토글팁 버튼 (사용자 지정)
- 패널 상단에 **"PRAMI ERP 데이터" 버튼**(ⓘ + 텍스트) → 누르면 공통 설명 팝오버(두 줄, Q-E2). 상시 박스 없음.
- **닫힘 동작(모든 InfoHint 통일 — Plan 결정)**: 바깥 클릭·탭, Esc, Tab 이탈, 그리고 **마우스가 버튼·팝오버 영역을 벗어나면 닫힘**.
  - pointerleave 는 `pointerType === 'mouse'` 일 때만, **약 200ms 지연** 후 닫기(버튼 ↔ 팝오버 이동 중 다시 들어오면 취소 — 깜빡임 방지).
  - 키보드로 연 경우(마우스 포인터가 영역에 없음)에는 pointerleave 로 닫지 않음 — Esc·Tab 이탈·바깥 클릭으로만. 팝오버 안에 포커스가 있는 동안에도 마우스 이탈 닫기는 적용(사용자 지시 우선)하되 포커스는 트리거로 복귀.
  - 열기는 클릭·탭·Enter·Space 만(hover 열기 없음). 터치는 바깥 탭으로 닫힘.
- 칸별 ERP 경로 ⓘ(항목 1~4)도 같은 컴포넌트·같은 닫힘 동작.
- Q-E2: 두 줄 유지.
### 6.2 Q-E3 = (a) 매칭 파일 업로드 신설 — **별도 PR(PR-2)**, 안내 PR(PR-1) 머지 후
기밀 원칙(최우선): 원본 파일은 **브라우저에서만** 읽는다. 서버로는 `{itemCode, materialCode}` 쌍만 전송. 원본·쌍 목록을 서버 저장·DB·로그·감사 상세·테스트 fixture 에 남기지 않는다(행별 링크 감사의 before/after 는 수동 확정과 같은 기존 동작이라 수용). 파일명도 저장·감사하지 않는다.
1. 위치: `/admin/costs/links` 상단 "매칭 파일 업로드" 영역(권한 `cost.write`), 항목 4 InfoHint 를 그 옆에.
2. 파싱(브라우저, `read-excel-file` 브라우저 빌드 동적 import): 시트 1개, **1행 제목 "품목조회(추가정보)", 2행 헤더, 3행부터 데이터**. 필수 헤더 "품번", "원자재품번(필수)" — 없으면 "품목-원가 매칭 파일 형식이 아닙니다" 로 거부. 사용하는 열은 이 둘뿐(원자재대체품·추가자재·기타 열 무시 — 이번 범위 밖). 파일 크기 상한 10MB, 행 상한 5,000. 빈 품번·빈 원자재품번 행은 건너뜀(건수만 표시).
3. 서버 `previewCostLinkImport(access, pairs)`(쓰기 없음, `server/cost`): §9 분류 — 같음 / 변경 / 추가 / 실패(품목 마스터 없음·후보 범위 밖·원가표에 없는 품번·한 품목에 품번 2+·형식 오류) / 파일에 없는 기존 링크 수(제품군별, **유지** — Q-F1). 결과는 응답(화면)에만.
4. 화면: 미리보기(건수 + 변경·추가·실패 목록 — 화면에만, 접기) → "확정(변경 N·추가 M)" → 결과. 미리보기와 확정 사이 데이터가 바뀌어 거부되면 "다시 미리보기" 안내.
5. 적용 `applyCostLinkImportAction`(`cost.write`): 변경·추가 쌍만 기존 `confirmCostLinks`(검사·트랜잭션·행별 감사) 로. 한 번에 500건 초과면 거부(현 실데이터 20건). 요약 감사 `cost_link.import`: after 에 `{saved, unchanged, failedByReason}` **건수만**, 파일명·목록 없음. 해제는 하지 않음.
6. 서버 로그: 쌍·품목코드 목록 금지 — 오류는 코드·건수만. `confirmCostLinks` VALIDATION 메시지가 품목코드를 나열하므로 미리보기에서 걸러 그 경로를 타지 않게 하고, 만약 나와도 로그에는 메시지 대신 오류 코드만.
