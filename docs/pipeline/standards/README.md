## 쓰는 법

- 각 항목: **출처(표준·조항) → Prami 에서 하는 일 → 남길 산출물 → 생략 조건**.
- "넣기" 항목은 본문에서 지킵니다. "참고" 는 끝에 링크만 두고, 필요할 때 찾아봅니다.
- **원문을 옮기지 않습니다.** ISO·IEEE·KS 는 유료 문서라 조항 번호와 우리 말로 쓴 요지만 둡니다. ISTQB·IREB 실러버스도 무료지만 저작물이라 인용하지 않습니다.

## 표기 규칙

- 국가표준이 있으면 `KS X ISO/IEC …` 로 쓰고 ISO 번호·연도를 병기합니다. KS 부합판이 확인되지 않은 표준은 ISO 번호만 쓰고 "(KS 부합판 미확인)" 을 붙입니다.
- 국제판과 KS 부합판의 연도가 다르면 둘 다 적고, **조항 번호는 국제 최신판 기준**으로 씁니다.
- 초안(draft)은 확정판처럼 인용하지 않습니다(예: NIST SSDF v1.2 초안).
